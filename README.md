# LABBAT — Bioarqueologia Translacional

Site oficial do Laboratório de Bioarqueologia Translacional do NPDM/UFC.

## Desenvolvimento

O projeto é um site estático sem dependências externas de construção.

```sh
npm run build
```

O comando gera a versão publicável em `dist/`. A página publicada no GitHub Pages é servida diretamente pela branch `main`.

## Estrutura

- `index.html`: conteúdo e estrutura da página
- `site.css`: identidade visual e responsividade
- `site.js`: navegação e transições da jornada
- `media/`: imagens utilizadas pela página
- `fonts/`: fonte local otimizada
